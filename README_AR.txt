بوت نجوم الرياضة النخبة — نسخة الاشتراكات

المميزات:
- /start لعرض الاشتراك الأسبوعي 200 جنيه أو الشهري 500 جنيه.
- عرض رقم فودافون كاش 01024689530.
- استقبال صورة إيصال التحويل.
- إرسال الإيصال للإدارة مع زري قبول ورفض.
- إرسال نتيجة المراجعة للمشترك.
- الإضافة إلى القناة/المجموعة تتم يدويًا بواسطة الإدارة.

ملفات المشروع:
- index.js: كود البوت.
- package.json: المكتبات وأمر التشغيل.

متغيرات البيئة المطلوبة على الاستضافة:
- BOT_TOKEN: توكن البوت من BotFather (سرّي، لا ترسله في المحادثات).
- ADMIN_ID: رقم حساب الإدارة، والقيمة الحالية 6809336258.
- CASH_NUMBER: رقم فودافون كاش، والقيمة الحالية 01024689530.

التشغيل:
1) Node.js 20 أو أحدث.
2) npm install
3) npm start

مهم:
- لا ترفع BOT_TOKEN إلى GitHub ولا تضعه داخل الكود.
- هذه النسخة تستخدم الذاكرة المؤقتة لحفظ الطلبات المعلقة؛ إعادة تشغيل الخدمة تمسح الطلبات التي لم يتم التعامل معها.
- لا تؤكد الدفع آليًا؛ قرار القبول أو الرفض بيد الإدارة بعد مراجعة الإيصال.
